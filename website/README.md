# Discord Server Splash Page

A sleek, animated landing page to invite people to your Discord server.

## Features
- Animated floating particles background
- 3D card tilt effect on hover
- Glowing orb atmosphere
- Animated member counters
- Ripple effect on join button
- Fully responsive

## Usage
1. Open `index.html` in any browser — no dependencies needed.
2. To change the invite link, find `https://discord.gg/v6Srecszt` in `index.html` and replace it.
3. Update the member/online counts by editing the `animateCount(...)` calls at the bottom of the script.

## Deploy on GitHub Pages
1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set source to `main` branch, root `/`.
4. Your page will be live at `https://yourusername.github.io/repo-name`.
